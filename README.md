# 부고란 — 뉴스를 오마주한 창작 매체

매체명: **부고란**. 부제: 사라진 것들의 신문.
신문 전체가 하나의 부고란이라는 뜻이다. 그래서 코너 "부고란"은 "오늘의 부고"로 이름을 바꾸고 1면 톱으로 올린다.

## 한 줄 정의
세상이 잊은 작은 것들을, 신문의 형식을 빌려 다시 쓰는 창작 매체.

## 선언문 (수정안)
> 우리는 뉴스를 전하지 않습니다. 뉴스의 모양을 빌립니다.
> 신문이 한 번도 싣지 않았거나, 실었다가 잊어버린 작은 것들을
> 부고에, 일기예보에, 광고란에, 인사란에 다시 올립니다.
> 이 신문은 통째로 하나의 부고란입니다.
> 씨앗은 실제로 있던 것이고, 글은 지어낸 것입니다.

## 운영 원칙
- AI 기자는 초안을 쓴다. 완성은 편집장(사람)이 한다. 고친 흔적은 공개하지 않는다.
- 지면의 틀은 한 번에 전부 잡는다. 가동은 단계별로 한다(1차 → 2차 → 3차).
- 자동화는 코너가 자리 잡은 뒤에만 붙인다. 처음에는 "오늘 ○○란 초안 가져와"로 수동 가동한다.
- 씨앗(출발점)은 반드시 실재하는 공적 자료에서 온다. 글은 허구임을 숨기지 않는다.

## 코너 간 연결
- 정정란(20)은 십자말풀이(21)의 정답 발표를 겸한다. "지난 호 십자말풀이의 정답을 바로잡습니다."
- 연재소설(23)의 노선은 완결 후 오늘의 부고(01)에 부고가 나간다.
- 1면 특집(19)의 씨앗은 사물의 사설(22)이 같은 호에 논평할 수 있다.

## 글 한 편의 공통 구성
1. 제목 (코너 양식이 정한 대로)
2. 본문
3. 서명: `기자 이름 / 편집 박멀미`
4. 이 글이 시작된 자리: 씨앗 한 줄 + 출처 링크
5. 편집장 주석 (선택. 난해한 결의 코너는 필수)

## 워드프레스 매핑
- 카테고리(상위) = 면: 1면, 사회면, 세계면, 경제면, 과학면, 문화면, 생활면, 인사면, 편집장
- 카테고리(하위) = 코너 24개
- 작성자 계정 = 기자 5명 + 편집장
- 사용자 정의 필드: `seed`(씨앗 한 줄), `seed_url`(출처), `editor_note`(편집장 주석), `editor_request`(재작성 지시), `corner`(코너 번호)
- 상태 흐름: 초안 생성 → `pending`(검토 대기) → 편집장 수정 → `publish`
  재작성이 필요하면 `editor_request`에 한 줄 쓰고 상태를 `draft`로 되돌린다.
- 태그: 결(인문학 / B급 / 난해함), 특집(같은 씨앗), 정정(실제 / 창작)

## 파이프라인 (코너 공통)
```
공급원에서 씨앗 후보 3건 + 각도  →  편집장이 1건 선택
  →  기자 지시문으로 초고 2편  →  자동 검사(분량·금지 표현·인명·개인정보)
  →  워드프레스 pending  →  편집장 수정·발행  (재작성이면 editor_request → draft → 재생성)
  →  편집장의 수정 차이를 다음 지시문의 사례로 축적 (비공개)
```

## 파일 구성
- `강령.md` — 편집 강령 (전 기자 공통 바탕)
- `기자.md` — 기자 다섯 명의 설계서와 담당 코너
- `공급원.md` — 씨앗 공급원 14개와 사용 규칙
- `corners/01~24 (01은 오늘의 부고)` — 코너별 설계서 겸 기자 지시문. 각 파일은 정의·형식 틀·공급원·지시문·자동 검사·재작성 지시 예시로 구성. 1차 코너에는 샘플 초안 포함
