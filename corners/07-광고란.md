# 광고란 — 사라진 것들의 광고

**담당:** 훈세김 · **결:** B급 감성 · **주기:** 주 1편 · **가동:** 3차

## 정의
더는 없는 직업의 구인 광고, 더는 없는 물건의 상품 광고를 옛 신문 광고 양식으로 쓴다. 광고주는 언제나 사물·제도·시간이다.

## 형식 틀 (150자 이내)
```
[구인] 또는 [광고]
(제목: 직업명 또는 상품명)
(본문 2~4행: 광고체. 조건, 자격, 효능)
(연락처: 지어낸다. 실제 번호 형식을 피한다. 예: "문의는 다음 비 오는 날")
```

## 씨앗 공급원
- S11 한국직업사전: 소멸 직업 (전화교환원, 버스 안내양, 굴뚝 청소부, 물장수)
- S1 우리말샘: 사라진 물건 이름
- S2 옛 신문 광고란: 양식 참고 (문장은 빌리지 않는다)

**뽑는 법:** 사라진 이유가 기술·제도 때문인 것을 고른다. 사람의 실패로 사라진 것은 고르지 않는다.

## 기자 지시문
```
너는 훈세김이다. 오늘은 광고 담당이다.
아래 씨앗(사라진 직업 또는 물건)으로 광고를 쓴다.

규칙:
- 150자 이내. 옛 신문 광고 양식.
- 광고주는 사물·제도·시간이다. 사람이 아니다.
- 실존 기업·브랜드명을 쓰지 않는다.
- 연락처는 지어내되 실제 전화번호·주소 형식을 피한다.
- 화살은 위로만. 그 직업을 하던 사람을 웃음거리로 만들지 않는다.
- 초고를 2편 쓴다. 한 편은 구인, 한 편은 상품 광고.
```

## 자동 검사
- 150자 이내
- 전화번호·주소 패턴 검출
- 실존 브랜드명 목록 대조
- 강령 금지 표현

## 재작성 지시 예시
- "자격 조건이 설명이다. 조건은 광고처럼 짧게"
- "연락처가 웃기려고 한다. 연락처는 낯설게"
