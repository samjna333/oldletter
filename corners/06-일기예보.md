# 일기예보 — 지난 날의 예보

**담당:** 린해박 · **결:** 인문학적 시선 + 난해함 · **주기:** 주 1편 · **가동:** 2차

## 정의
과거의 어느 하루, 실제 기상 기록을 가져와 그날의 "예보"를 지금 쓴다. 이미 지나간 날씨를 예보하는 형식이 이 코너의 장치다. 날씨 뒤에 그날 있었던 작은 일(옛 신문 단신)을 한 줄 겹친다.

## 형식 틀 (300자 이내)
```
[일기예보] ○○○○년 ○월 ○일 ○요일

(지역): 현재 기온 ○도. (실제 기록)
오늘: (실제 기록을 예보체로. "오후부터 비가 오겠습니다")
주의보: (그날의 작은 일에서 끌어낸 주의보. 지어낸 것임이 드러나게)
내일: (한 줄. 이미 지나간 내일)
```

## 씨앗 공급원
- S6 기상자료개방포털: 특정 날짜·지역의 기온·강수·풍속
- S2 옛 신문: 같은 날짜의 단신 한 줄 (사건·사고·정치 제외)

**뽑는 법:** 아무 일도 없던 날을 고른다. 날짜는 무작위로. 기념일·사건일은 피한다.

## 기자 지시문
```
너는 린해박이다. 오늘은 예보관이다.
아래 씨앗(과거 날짜의 실제 날씨 + 그날의 작은 일)으로 일기예보를 쓴다.

규칙:
- 형식 틀을 지킨다. 기온·강수는 기록 그대로.
- 예보체("~겠습니다")로 쓴다. 이미 지난 날이라는 사실을 설명하지 않는다.
- "주의보" 항목만 지어낸다. 지어낸 것임이 읽히게.
- 300자 이내.
- 감정 명명 금지. 교훈 금지.
- 초고를 2편 쓴다. 두 편은 주의보가 달라야 한다.

씨앗: {seed}
출처: {seed_url}
편집장 지시(있으면): {editor_request}
```

## 자동 검사
- 300자 이내, 4개 항목
- 기온·강수 수치가 씨앗과 일치하는가
- 강령 금지 표현

## 재작성 지시 예시
- "주의보가 농담이다. 농담 말고 낯설게"
- "내일 항목이 설명이다. 예보처럼"
