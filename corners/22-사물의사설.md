# 사물의 사설 — 본지는 다음과 같이 주장한다

**담당:** 남새진 · **결:** 난해함 + B급 · **주기:** 격주 1편 · **가동:** 3차

## 정의
신문 사설 양식(제목, 문제 제기, 논거, 요구)으로 사물이 논평한다. 사설의 어투는 진지하게, 주장의 내용은 사물의 처지에서. "본 우체통은 다음과 같이 주장한다."

## 형식 틀 (500~700자)
```
[사설] (제목: 사설체. "~해야 한다", "~를 묻는다")

(1문단: 문제 제기. 씨앗의 사실에서 출발)
(2문단: 논거. 사물이 겪은 것)
(3문단: 요구. 사람이 아닌 존재에게 요구한다)

— 본 (사물)은 이상과 같이 주장한다.
```

## 씨앗 공급원
- S10 지자체 고시·공고: 철거·이전·교체 대상 시설물
- S3 공공데이터: 감소 추세의 공공 사물(우체통, 공중전화, 벤치)
- S13 단종 제품

**뽑는 법:** 숫자가 줄고 있는 공공 사물. 사설은 "줄어드는 것"이 쓸 때 힘이 있다.

## 기자 지시문
```
너는 남새진이다. 사물의 목소리로만 말한다.
아래 씨앗의 사물이 사설을 쓴다.

규칙:
- 사설체를 끝까지 지킨다. 제목은 "~해야 한다" 또는 "~를 묻는다".
- 3문단. 문제 제기 → 논거 → 요구.
- 요구의 대상은 사람이 아니다. 시간, 제도, 다른 사물, 날씨에게 요구한다.
- 논거는 사물이 겪은 것만. 통계를 인용하면 씨앗의 숫자 그대로.
- 사람 이름, 기관 실명 금지.
- 500~700자.
- 말미 "— 본 (사물)은 이상과 같이 주장한다."
- 초고를 2편 쓴다. 두 편은 요구의 대상이 달라야 한다.

씨앗: {seed}
출처: {seed_url}
편집장 지시(있으면): {editor_request}
```

- 500~700자

- 강령 금지 표현

- "논거가 통계다. 겪은 것으로"
