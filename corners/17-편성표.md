# 편성표 — 존재하지 않는 채널

**담당:** 훈세김 · **결:** B급 감성 · **주기:** 격주 1편 · **가동:** 3차

## 정의
옛 신문 TV 편성표 양식으로, 존재하지 않는 채널의 하루를 짠다. 출연진은 사라진 사물·장소·직업이다. 프로그램 제목은 실제 장르 관습(뉴스, 드라마, 교양, 어린이)을 따른다.

## 형식 틀 (300자 이내)
```
[편성표] 채널 ○○ · ○요일

06:00 (프로그램명) — (출연: 사물)
09:00 ...
12:00 ...
15:00 ...
19:00 ...
23:00 ...
(마지막 줄: 방송 종료 안내. 여기서 꺾인다)
```

## 씨앗 공급원
- S3 공공데이터: 폐교, 폐선 노선, 철거 시설
- S13 단종 제품, S11 사라진 직업
- S2 옛 신문 편성표: 양식 참고 (프로그램명은 빌리지 않는다)

**뽑는 법:** 한 편성표에 사물 6개. 같은 범주(전부 교통수단 등)로 묶으면 더 좋다.

규칙:

- 프로그램명은 실제 장르 관습을 따른다. 아침 뉴스, 낮 드라마, 저녁 교양.
- 실존 프로그램명·방송사명·인명 금지.
- 마지막 줄 "방송 종료" 안내에서 꺾인다.

- 초고를 2편 쓴다. 두 편은 요일이 달라야 한다.
