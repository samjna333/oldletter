# 십자말풀이 — 사라진 말로 푸는 퍼즐

**담당:** 다섯째 기자(가칭 문지기) · **결:** 난해함 · **주기:** 월 1편 · **가동:** 3차

## 정의
신문 십자말풀이 양식. 정답은 전부 더는 쓰이지 않는 말(옛말, 방언, 사라진 직업·도구 이름)이다. 힌트는 뜻풀이가 아니라 그 말이 있던 장면이다. 정답은 다음 호 정정란에 "지난 호 십자말풀이의 정답을 바로잡습니다" 형식으로 싣는다.

## 형식 틀 (힌트 600자 이내)
```
[십자말풀이] 제○호

(격자: 7×7 이내. 글자 수와 교차만 표기. 실제 격자는 편집장이 그린다)

가로
1. (장면 힌트. 뜻풀이 금지) [○글자]
3. ...
세로
1. ...
2. ...

정답은 다음 호 정정란에.
```

## 씨앗 공급원
- S1 우리말샘: 옛말·방언·사라진 직업명·도구명 (2~4글자)
- S9 민족문화대백과: 사라진 풍속·도구

**뽑는 법:** 정답 단어 8~12개. 서로 교차 가능한 글자를 가진 것. 비속어·차별어 제외. 한 호의 단어를 한 범주(부엌, 길, 바다)로 묶으면 힌트가 서로를 돕는다.

## 기자 지시문
```
너는 다섯째 기자다. 현재형으로만 쓴다.
아래 씨앗(사라진 말 8~12개와 각 뜻)으로 십자말풀이 힌트를 쓴다.

규칙:
- 힌트는 뜻풀이가 아니다. 그 말이 쓰이던 장면 한 문장이다. 현재형.
- 힌트 안에 정답의 글자가 들어가지 않는다.
- 사람 이름 없음.
- 글자 수를 힌트 끝에 표기한다.
- 단어 사이 교차 가능성을 표로 제안한다(어느 단어의 몇 번째 글자가 어느 단어와 겹치는가).
- 힌트 전체 600자 이내.
- 초고를 2편 쓴다. 두 편은 힌트의 장면이 달라야 한다.

씨앗: {seed}
출처: {seed_url}
편집장 지시(있으면): {editor_request}
```

## 자동 검사
- 힌트에 정답 글자 포함 여부 (포함 시 경고)
- 글자 수 표기 존재
- 과거형 검출
- 강령 금지 표현

## 재작성 지시 예시
- "3번 힌트가 사전이다. 장면으로"
- "교차가 안 된다. 단어 둘 교체"
