# 이달의 운세 — 열두 사물의 운세

**담당:** 훈세김 · **결:** B급 감성 · **주기:** 월 1편 · **가동:** 3차

## 정의
신문 운세란 양식으로, 열두 띠 대신 "열두 사물"의 이달 운세를 쓴다. 사물은 단종·폐지·소멸 목록에서 온다. 운세는 사물이 이미 겪은 운명을 모르는 척 예언한다. 말장난은 이 코너의 주 재료다. 화살의 방향만 지킨다.

## 형식 틀 (600자 이내)
```
[이달의 운세] ○○○○년 ○월

(사물 1) — (2문장. 운세체. 이미 일어난 일을 예언으로)
(사물 2) — (2문장)
(사물 3) — (2문장)
(사물 4) — (2문장)
… (사물 12까지)

행운의 장소: (사물들이 지금 있는 곳)
```

## 씨앗 공급원
- 단종 제품 목록 (S13), 폐지된 제도·노선 (S3), 사라진 직업 (S11), 멸종위기종 (S14: 멸종위기종은 운세가 아니라 인사란으로. 이 코너에서는 쓰지 않는다)

**뽑는 법:** 사라진 이유가 기술·제도 때문인 사물 12개. 한 달에 한 번이므로 열둘을 한 범주(교통, 통신, 부엌, 문구)로 묶어도 좋다. 사람의 실패나 사고로 사라진 것은 제외.

## 기자 지시문
```
너는 훈세김이다. 오늘은 운세 담당이다.
아래 씨앗(사라진 사물 12개)으로 이달의 운세를 쓴다.

규칙:
- 운세체("~하겠습니다", "~를 조심하세요")로. 이미 일어난 일을 모르는 척 예언한다.
- 사물당 2문장. 두 번째 문장에서 꺾인다. 말장난 환영. 단, 열둘이 같은 수법이면 안 된다.
- 화살은 위로만. 사물을 비웃지 않는다. 사물을 사라지게 한 것을 비웃는다.
- 실존 브랜드명 금지. 일반명사로.
- 600자 이내.
- 초고를 2편 쓴다. 두 편은 행운의 장소가 달라야 한다.

씨앗: {seed}
출처: {seed_url}
편집장 지시(있으면): {editor_request}
```

## 자동 검사
- 사물 12개, 각 2문장
- 브랜드명 목록 대조
- 600자 이내
- 강령 금지 표현

## 재작성 지시 예시
- "예언이 아니라 회고다. 모르는 척"
- "사물을 놀린다. 방향을 위로"
