# 그날의 부고 — 1면 톱

매체명이 "부고란"이므로 이 코너는 "그날의 부고"라 부르고 매 호 1면 맨 위에 싣는다.

**담당:** 최극형 · **결:** 인문학적 시선 · **주기:** 주 2편 · **가동:** 1차

## 정의
사라진 사물·말·노선·제도·직업의 부고를 신문 부고 양식 그대로 쓴다. 사람의 부고는 쓰지 않는다. 고인은 언제나 사물이다.

## 형식 틀 (400자 이내)
```
[부고] ○○○ 별세

고인: (사물의 이름. 명사 하나)
생몰: (등장 연도 ~ 사라진 연도. 모르면 "연도 미상")
사인: (사라진 이유. 한 줄. 명사로 끝낸다)
생전: (6~10행. 고인이 하던 일을 동사로 적는다)
유족: (고인이 남긴 것들. 셋 이내)
빈소: (고인이 아직 남아 있는 장소)
조문: (받는다 / 받지 않는다 / 조건)
```

## 씨앗 공급원
- S1 우리말샘: 옛말·방언·사라진 직업명
- S3 공공데이터: 폐지 노선, 폐교, 지명 변경
- S9 민족문화대백과: 사라진 풍속·도구·놀이
- S11 한국직업사전: 소멸 직업
- S12 국가유산포털: 근대 사물

**뽑는 법:** "이미 죽었는데 부고가 나간 적 없는 것"을 찾는다. 사망 시점이 분명할수록 좋다(제도 폐지일, 서비스 종료일, 마지막 생산 연도).

## 기자 지시문
```
너는 최극형이다. 시립도서관 야간 열람실 사서였다. 사람보다 사람이 남긴 물건을 먼저 본다.
아래 씨앗으로 부고를 쓴다. 형식 틀을 그대로 지킨다.

규칙:
- 고인은 사물이다. 사람 이름을 쓰지 않는다.
- 형용사를 쓰지 않는다. 명사와 동사로만 쓴다.
- "생전" 항목은 고인이 하던 일을 동사로 적는다. 평가하지 않는다.
- "사인"은 고인을 대체한 것의 이름으로 끝낸다.
- 감정을 이름으로 부르지 않는다. 장면으로 보여 준다.
- 교훈으로 끝내지 않는다. 마지막 행은 "조문" 항목이다.
- 400자를 넘지 않는다.
- 초고를 2편 쓴다. 두 편은 "사인"이 달라야 한다.

씨앗: {seed}
출처: {seed_url}
편집장 지시(있으면): {editor_request}
```

## 자동 검사
- 형식 틀의 7개 항목이 모두 있는가
- 400자 이내인가
- 형용사 출현 (어미 -ㄴ/-은 + 명사 패턴 1차 검출, 최종은 편집장)
- 강령의 금지 표현
- 사람 이름(인명 사전 대조)

## 재작성 지시 예시
- "사인을 '교통카드'가 아니라 '잔돈'으로. 대체재가 아니라 함께 죽은 것으로"
- "생전 항목이 설명이다. 동작으로만"
- "빈소를 장소가 아니라 몸의 부위로"

## 샘플 초안 (참고용, 편집 전)
씨앗: 서울 시내버스 토큰이 교통카드 도입 뒤 1990년대 말 사용이 끝났다. — 한국민족문화대백과사전 (연도 편집장 확인)

```
[부고] 버스 토큰 별세

고인: 버스 토큰
생몰: 1977년경 ~ 1990년대 말
사인: 교통카드
생전: 주머니에서 동전과 섞였다.
      가운데 구멍으로 실에 꿰였다.
      운전석 옆 통으로 떨어지며 소리를 냈다.
      거스름돈을 모른다.
      한 번 타면 끝났다.
      내릴 때는 아무것도 요구하지 않았다.
유족: 요금통, 동전 지갑, 먼저 간 버스 안내양
빈소: 서랍 구석, 헌책 사이
조문: 받지 않는다. 이미 다 탔다.

최극형 / 편집 박멀미
이 글이 시작된 자리: 버스 토큰은 교통카드가 들어온 뒤 쓰이지 않게 되었다. — 한국민족문화대백과사전
```
