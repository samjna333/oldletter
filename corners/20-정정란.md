# 정정란 — 지난 호의 정정

**담당:** 편집장 (AI 초안 허용) · **주기:** 필요할 때 · **가동:** 2차

## 정의
신문 정정 보도 양식을 빌린다. 두 종류가 있다.
1. **실제 정정:** 씨앗 표기의 사실 오류(연도, 명칭)를 고친다. 강령의 정정 원칙 그대로.
2. **창작 정정:** 지난 호 글의 허구를 허구로 정정한다. "지난 호 부고란의 버스 토큰은 ○○ 서랍에서 생존이 확인되었습니다."

두 종류는 섞어 싣되, 실제 정정이 창작 정정처럼 읽히지 않게 표시를 달리한다.

## 십자말풀이 정답
지난 호 십자말풀이(21)의 정답을 이 지면에서 "바로잡습니다" 형식으로 발표한다. □ 표시(창작 정정)로 싣는다.

## 형식 틀 (각 100자 이내)
```
[정정] (실제 정정: ■ 표시)
■ ○월 ○일 자 (지면) "(제목)"에서 (틀린 것)은 (맞는 것)의 잘못이므로 바로잡습니다.

[정정] (창작 정정: □ 표시)
□ ○월 ○일 자 (지면) "(제목)"에서 (허구의 정정).
```

## 기자 지시문 (창작 정정만)
```
아래 지난 호 글에 대해 창작 정정 한 줄을 쓴다.

규칙:
- 정정 보도체. "바로잡습니다"로 끝내지 않는다(실제 정정과 구분).
- 글의 허구를 더 밀고 가는 정정. 글을 무효로 만드는 정정은 안 된다.
- 100자 이내. □ 표시로 시작.

지난 호 글: {post}
```

## 자동 검사
- 실제 정정(■)은 편집장이 직접 쓴 것만 발행 (AI 초안 차단)
- 창작 정정(□)이 "바로잡습니다"로 끝나면 경고
