# 1면 특집 — 같은 씨앗, 다섯 개의 시선

**담당:** 전 기자 · **주기:** 월 1회 · **가동:** 2차 (1차 코너 3개가 안정된 뒤)

## 정의
씨앗 하나를 다섯 기자가 각자의 지면 양식으로 쓴다. 매체의 정체성을 가장 선명하게 보여 주는 형식이며, 1면에 다섯 편을 나란히 싣는다.

## 형식
- 편집장이 씨앗 하나를 고른다. 씨앗은 다섯 양식 모두에 들어갈 수 있어야 한다(사물이고, 시기가 있고, 장소가 있는 것).
- 각 기자는 자기 본 지면의 양식으로 쓴다: 최극형(부고 또는 산문시), 훈세김(세 줄 뉴스), 린해박(숫자 에세이 또는 시세), 남새진(사물의 편지), 다섯째 기자(낱말 또는 사진).
- 다섯 편의 순서는 짧은 것부터.
- 편집장 주석은 다섯 편에 하나만.

## 파이프라인
```
씨앗 하나 → 기자 5명에게 동시에 → 각자 초고 2편 → 편집장이 기자당 1편 선택 → 1면
```

## 제약
- 다섯 편이 서로를 언급하지 않는다. 독자가 나란히 놓고 읽을 때만 연결된다.
- 씨앗 표기는 1면 하단에 한 번만.

## 좋은 씨앗의 예
- 폐지된 시외버스 노선 하나 (부고·세 줄·숫자·편지·사진 모두 가능)
- 단종된 필름 한 종류
- 이름이 바뀐 역 하나
