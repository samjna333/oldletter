# 디자인

- `front-page.html` — 1면 시안 2판. 서체는 고운바탕 하나. 밝은 종이색, 옅은 괘선, 주홍 인장 부제, 형광 노랑 마커.
- 강조 장치 다섯: 굵게(700), 방점(text-emphasis), 형광펜(배경 그라데이션), 주홍 글자(지어낸 부분 표시), 자간 넓힘·괘선 상자(라벨·명사).
- 서체 로딩: 구글 폰트의 한글 조각 방식(unicode-range). 1면 전체 분량 기준 실측 약 500KB(고운바탕 2굵기 31조각), 재방문 시 캐시.
- 제호는 운영 시 SVG로 교체해 서체 의존을 없앤다.
- 자식 테마(Uncode Child)가 활성 상태라 CSS는 테마 편집기나 Uncode 옵션의 사용자 CSS에 넣는다. FTP 불필요.
